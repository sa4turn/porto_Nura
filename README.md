# Nuraa Portfolio

Nur'Aini Dwi Novianti Ismail's personal portfolio, built with vanilla HTML, CSS, and JavaScript.

## Run in VS Code

1. Extract the project folder.
2. Open the `porto` folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html`, then select **Open with Live Server**.

The website can also be opened directly by double-clicking `index.html`.

## Structure


## Edit the Content

- The profile, experience, education, and project cards are in `index.html`.
- Project pop-up details are stored in the `projectData` object at the top of `script.js`.
- The main colors can be adjusted through the variables in the `:root` section of `styles.css`.
