# Nuraa Portfolio

Portofolio pribadi Nur'Aini Dwi Novianti Ismail menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan di VS Code

1. Ekstrak folder proyek.
2. Buka folder `nuraa-portfolio-vscode` di VS Code.
3. Instal ekstensi **Live Server**.
4. Klik kanan `index.html`, lalu pilih **Open with Live Server**.

Website juga dapat dibuka langsung dengan mengeklik `index.html`.

## Struktur

```text
nuraa-portfolio-vscode/
├── assets/
│   ├── nuraa-profile.webp
│   ├── melonku.webp
│   ├── toko-amalia.webp
│   ├── etika-filter.webp
│   ├── tiktok-effects.webp
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Mengedit isi

- Identitas, pengalaman, pendidikan, dan kartu proyek berada di `index.html`.
- Detail pop-up proyek berada pada objek `projectData` di bagian paling atas `script.js`.
- Warna utama dapat diubah melalui variabel pada bagian `:root` di `styles.css`.

## Publikasi GitHub Pages

1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini, bukan file ZIP-nya.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`, kemudian simpan.
